# StockSage 产品文档

## 概述

StockSage 是一个 **AI 驱动的美股分析平台**，面向个人投资者，帮助用户在信息过载的市场中快速获取有洞察力的股票分析。平台聚合新闻、行情、技术指标和基本面数据，通过 AI 模型生成每日摘要和综合评分（0-100），让普通投资者也能获得专业级的投研辅助。

**网址**: [stocksage.xyz](https://stocksage.ai)（以实际部署域名为准）

---

## 目标用户与核心痛点

| 痛点 | StockSage 解决方案 |
|------|-------------------|
| **信息过载** — 每天数百条财经新闻，无法分辨哪些重要 | AI 每日摘要：自动阅读相关新闻，提炼关键催化剂和风险点 |
| **分析门槛高** — 技术指标、基本面数据散落各处，难以综合判断 | AI 评分（0-100）：融合技术面、基本面、新闻情绪，给出统一的买入/持有/卖出信号 |
| **盯盘耗时** — 需要持续关注股价波动和新闻 | 每日邮件摘要：早上 8 点推送个性化股票简报，无需时刻盯盘 |
| **选股困难** — 不知道从哪里开始研究 | 市场热力图 + Learning Center 教育文章，帮助发现机会、学习方法 |

## 功能清单

### 1. AI 股票评分（0-100 分）

**解决什么问题**：将复杂的多维度数据综合成一个直观的分数，帮助快速判断。

- 综合 **技术面**（MA/RSI/MACD/Bollinger）、**基本面**（行业/市值）、**新闻情绪**（正面/负面/中性）
- 输出 0-100 的综合评分 + Buy / Hold / Sell 信号
- AI Pipeline 每日定时运行，拉取最新新闻 → LLM 摘要 → LLM 评分 → 存入数据库

**入口**：任意股票详情页的 AI Analysis 区域

---

### 2. AI 新闻摘要

**解决什么问题**：人工阅读数十篇财经新闻耗时且低效。

- AI 自动聚合每只股票的最新新闻
- 生成简洁的要点摘要，标注关键催化剂和风险
- 支持多数据源（Finnhub + Yahoo Finance）

**入口**：股票详情页 → NewsTab

---

### 3. 个性化 Watchlist

**解决什么问题**：聚焦自己关注的股票，不受无关信息干扰。

- 添加/删除自选股票
- Dashboard 总览：实时行情 + 技术信号 + AI 评分摘要
- Free 用户最多 3 只，Pro 用户无限

**入口**：Dashboard（`/dashboard`）、Watchlist 管理页

---

### 4. 每日邮件摘要

**解决什么问题**：不用打开网站也能了解持仓动态。

- 每天早上定时发送个性化股票简报
- 包含 AI 评分、关键新闻、技术信号
- 用户可自定义接收频率：每日摘要 / 每周总结 / 价格提醒（UI 开关）
- 可自定义发送时间（UTC 小时）

**入口**：Newsletter 偏好设置（`/newsletter`）

---

### 5. 市场热力图

**解决什么问题**：一眼看清 S&P 500 整体涨跌格局，发现领涨/领跌板块。

- 基于 S&P 500 成分股实时行情
- 按板块（Sector）和市场市值（Market Cap）分组
- 绿涨红跌，面积代表市值权重
- 支持 Treemap 交互式可视化

**入口**：`/heat`

---

### 6. 股票详情页

**解决什么问题**：一站式查看单只股票的所有关键信息。

- 实时行情（价格、涨跌幅、成交量）
- AI 分析区：新闻摘要 + 评分 + 买卖信号
- SEO 优化：动态 OG 图片（含价格和涨跌幅）、结构化数据（BreadcrumbList + FAQPage）
- 支持搜索任意美股（NYSE / NASDAQ），Ctrl+K 快速唤起搜索

**入口**：`/stock/[ticker]`，或 Header 搜索框

---

### 7. Learning Center

**解决什么问题**：投资新手缺乏系统知识，不知道从何学起。

- 免费投资教育文章
- 涵盖：投资组合构建、市场周期、复利、价值投资、指数投资等
- 每篇文章有独立 SEO（动态 metadata + OG 标签）

**入口**：`/learn`

---

### 8. 用户系统

- **仅 Google OAuth 登录**（无邮箱/密码注册，降低安全风险）
- Tier 分级：Free / Pro（$9.99/月）
- Settings 页面展示当前 Tier 和 Pro 到期时间
- 支付通过 Creem（MoR）处理

**入口**：`/login`、`/settings`、`/pricing`

## 技术架构

| 层级 | 技术 |
|------|------|
| 前端框架 | Next.js 16 (App Router) + React 19 |
| UI | Tailwind CSS 4 + shadcn/ui + Radix UI |
| 图表 | lightweight-charts（K 线 + 技术指标） |
| 数据库 | PostgreSQL (Supabase) + Prisma ORM |
| 认证 | Supabase Auth（Google OAuth） |
| 支付 | Creem（MoR，测试环境 test-api.creem.io） |
| AI | OpenAI SDK 兼容 API（模型通过 `LLM_MODEL` 环境变量配置） |
| 邮件 | Resend + @react-email/components |
| 行情数据 | Yahoo Finance（实时行情/K 线）、Finnhub（新闻） |
| 定时任务 | GitHub Actions（cron workflow） |
| 部署 | Vercel |

---

## 数据刷新机制

- **盘中（每 15 分钟）**：GitHub Actions cron 自动刷新所有股票的实时报价
- **盘后**：完整数据管道（K 线 + 基本面）更新
